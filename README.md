# English Trainer

Interaktivní webová aplikace pro výuku angličtiny (rozhraní česky). Uživatel zadá svou
úroveň (A1–C1) ručně nebo zařazovacím testem a procvičuje slovíčka a gramatiku.

## Funkce
- Kartičky se slovíčky a opakováním
- Kvíz, psaní překladu, doplňování gramatiky
- XP, série dní, přehled pokroku (ukládá se v prohlížeči)

## Spuštění
Otevři `index.html` v prohlížeči, nebo využij GitHub Pages.
